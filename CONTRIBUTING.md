# Contributing

Describe the Zotero version, operating system, steps to reproduce, expected result and actual result when reporting a problem. Use synthetic references and remove personal file paths from examples.

Run the automated tests and build the XPI before submitting a change. For changes affecting library records, include a test for the changed behavior and its failure case. Test privileged integration harnesses only in a disposable Zotero profile.

The current internal add-on ID is retained for compatibility. Changes to that ID, backup formats, or storage keys require a migration plan.
