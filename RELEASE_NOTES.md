# ZotSweep 1.0.0

Review missing PDF attachments and references without attachments, then move selected records to Zotero Trash.

Install `ZotSweep_v1.0.0.xpi` through Zotero: Tools > Plugins > gear menu > Install Plugin From File.

If Zotero refuses to replace an older-named 1.1.0 build with 1.0.0, remove that add-on, restart Zotero, then install this build.

Automated tests pass. Live Zotero and native Windows testing have not been repeated for the branding release. Read the README before using the plugin with a working library.
